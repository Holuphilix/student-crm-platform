## 📌 Overview

Full stack CRM platform for managing:
- student leads
- realtime conversations
- deal pipelines
- sales assignments
- role-based workflows

Built as part of the SINC Full Stack Developer Test of Competence.

## 🛠️ Stack

- React
- TypeScript
- Vite
- Hono
- Cloudflare Workers
- Supabase
- TanStack Query
- Tailwind CSS
- shadcn/ui
